## In one sentence

Spanish builds many words from a root plus **prefixes** (before) and **suffixes** (after); knowing them helps you guess the meaning of new words and write more precisely.

## Form

| Prefix | Meaning | Example |
|---|---|---|
| **in- / im- / i-** | not | *imposible, inútil, ilegal* |
| **des-** | opposite, undoing | *deshacer, desconfiar, desacuerdo* |
| **re-** | again; intensity | *rehacer, reconstruir, revisar* |
| **pre-** | before | *prever, prehistoria, preparar* |
| **sobre- / sub-** | above / below | *sobrevivir, subestimar* |
| **multi- / inter-** | many / between | *multicultural, internacional* |

| Suffix | Forms | Example |
|---|---|---|
| **-ción / -sión** | action nouns | *organizar → organización* |
| **-miento** | action nouns | *crecer → crecimiento* |
| **-dad / -tad** | quality nouns | *libre → libertad, feliz → felicidad* |
| **-ismo / -ista** | ideas / people | *periodismo, periodista* |
| **-mente** | adverbs | *rápida → rápidamente* |
| **-able / -ible** | possible | *reciclable, increíble* |
| **-oso / -osa** | full of | *peligroso, ruidoso* |
| **-ero / -era** | job or container | *panadero, zapatero, ensaladera* |
| **-ito / -ita, -ón / -ona** | diminutive / augmentative | *casita, grandullón* |

## Use

- **Guess new words:** *infravalorado* = *infra-* (under) + *valorar* → underrated.
- **Build families:** *pensar → pensamiento, pensativo, impensable, repensar.*
- **Vary your writing:** use the noun instead of the verb to sound more formal: *se decidió → la decisión*.

## Contrast with English

- English *-tion* matches Spanish **-ción**, but the stress moves: *organi-ZA-tion* / *organi-za-CIÓN*.
- English *-ly* matches **-mente**, which attaches to the feminine form: *slow → lenta → lentamente*.
- English *-able* and *-ible* correspond to **-able** and **-ible** (*reciclable*, *increíble*), and the choice depends on the word (many verbs in *-ar* take *-able*).

## Common mistakes

- ✗ *Inposible.* → ✓ ***Im**posible.* (before *p* and *b*)
- ✗ *Rápidomente.* → ✓ ***Rápidamente.*** (feminine form + *-mente*)
- ✗ *Realmente y rápidamente* in a series, repeated many times → ✓ *Real y rápidamente* (in formal style, only the last adverb keeps *-mente*).
- ✗ *Incredible* → ✓ *Increíble.*

## How it sounds

In adverbs in **-mente** there are two stresses: *rápidamente* is **RÁ**-pi-da-**MEN**-te. The suffix **-ción** is always stressed: orga-ni-za-**CIÓN**.
