# A1 — Acceso

> Usuario básico. Entiendes y usas expresiones cotidianas muy frecuentes para necesidades inmediatas, si te hablan despacio y con claridad.
> **Para ti:** nivel superado. Se usa como **repaso dirigido** si el test de nivel detecta huecos y como base del banco de drills (números, sonidos básicos).

---

## 1. Perfil

Puedes presentarte, hablar de ti con frases memorizadas, entender números, precios y horas, y leer carteles y mensajes muy cortos. Necesitas que el interlocutor colabore: que hable despacio, repita y reformule.

---

## 2. Descriptores «puedo»

### Listening
- **L-A1-01** Entiendo números, precios, horas y fechas dichos despacio y con claridad.
- **L-A1-02** Entiendo palabras y frases muy básicas sobre mí, mi familia y mi entorno.
- **L-A1-03** Sigo instrucciones cortas y sencillas.
- **L-A1-04** Reconozco saludos, despedidas y fórmulas de cortesía.
- **L-A1-05** Capto el tema de una conversación muy corta y lenta sobre algo cotidiano.

### Reading
- **R-A1-01** Entiendo nombres, palabras y frases muy sencillas en carteles y letreros.
- **R-A1-02** Entiendo mensajes muy cortos (notas, postales, SMS) sobre temas cotidianos.
- **R-A1-03** Encuentro un dato concreto (hora, precio, lugar) en un horario o un menú.
- **R-A1-04** Sigo instrucciones escritas muy simples con apoyo visual.
- **R-A1-05** Entiendo formularios básicos.

### Writing
- **W-A1-01** Relleno formularios con mis datos personales.
- **W-A1-02** Escribo mensajes y postales muy cortas.

### Speaking
- **S-A1-01** Me presento y respondo a preguntas sencillas sobre mí.
- **S-A1-02** Pido y doy cosas, horas y precios con frases aprendidas.

## 3. Especificación de audio

| Parámetro | Valor |
|---|---|
| Velocidad | 90–110 ppm, pausas claras entre frases |
| Duración | 20–60 s |
| Hablantes | 1–2 |
| Acentos | en-US, en-GB |
| Géneros | Diálogos de servicio (cafetería, tienda), presentaciones, anuncios muy simples, mensajes de voz cortos |
| Habla conectada | Contracciones básicas (*I'm, it's, don't*), formas débiles de *a, the, and* |
| Tareas | `mcq` de detalle, `true_false_ng` (sin «not given»), `gap_fill` de números/horas, `matching` persona–dato, dictado de palabras y números |

## 4. Especificación de texto

| Parámetro | Valor |
|---|---|
| Longitud | 50–150 palabras |
| Géneros | Carteles, notas, mensajes, menús, horarios, perfiles, postales |
| Cobertura objetivo | ≥ 98 % respecto al perfil A1 |
| Velocidad lectora objetivo | 60–90 ppm |
| Tareas | `mcq` de detalle, `true_false_ng`, `matching`, búsqueda de un dato |

## 6. Vocabulario

- **Tamaño orientativo:** < 1.500 lemas reconocidos.
- **Temas:** datos personales, familia, números, colores, días y meses, la hora, comida y bebida, la casa, la ciudad, la rutina, la ropa, el tiempo atmosférico, aficiones, trabajo y estudios (básico).
- **Foco:** palabras de máxima frecuencia, *chunks* de cortesía (*Can I have…?, Excuse me, How much is it?*).

## 7. Funciones

Saludar y despedirse · presentarse · deletrear · pedir y dar datos personales · pedir algo en una tienda o cafetería · decir la hora y fechas · expresar gustos.

## 9. Evaluación

Sin prueba de confirmación propia para ti (nivel superado). Si el test de nivel detecta huecos, se generan **paquetes de refuerzo** de 3–5 lecciones sobre lo detectado.
