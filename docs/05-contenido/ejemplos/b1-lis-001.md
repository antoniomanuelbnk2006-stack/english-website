> **Qué es:** una lección de escucha completa en formato **borrador** (`ListeningDraft`), lista para el pipeline mínimo (anotar → TTS → audio → subir). Sirve como plantilla, como dato de prueba para los tests y como primera lección real de la app.

---

## 1. Por qué está hecha así

| Decisión | Motivo pedagógico |
|---|---|
| Diálogo para planear algo con una pequeña tensión (es martes, Leo trabaja el miércoles) | Las situaciones con decisión se siguen mejor y obligan a entender actitudes, no solo datos |
| Números y horas con trampa (*forty*/*fourteen*, *half eleven*) | Puntos débiles típicos de hispanohablantes; distractores realistas |
| Dos acentos (británico y estadounidense) | Exposición a *car park*, *half eleven* (UK) y al *flap* de la *t* (US: *pretty cool*, *got it*) |
| Rasgos de habla conectada marcados | Alimentan el dictado diagnóstico y los drills |
| Una pregunta «no se dice» (NG) | Entrena a no inventar información |
| Opciones parafraseadas | Para acertar hay que entender, no reconocer palabras sueltas |
